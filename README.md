# outline-fonts

**OutlineText**, un convertisseur de texte en caractères Unicode stylés, à copier-coller partout (Instagram, TikTok, Discord, pseudos…).

👉 https://esaricam902-prog.github.io/outline-fonts/

## Fonctionnalités

- Conversion en temps réel vers le style **Outline / double barre** (𝔸𝔹ℂ𝕒𝕓𝕔𝟙𝟚𝟛)
- Plus de 20 autres styles : 𝐠𝐫𝐚𝐬, 𝑖𝑡𝑎𝑙𝑖𝑞𝑢𝑒, 𝓼𝓬𝓻𝓲𝓹𝓽, 𝔤𝔬𝔱𝔥𝔦𝔮𝔲𝔢, 𝚖𝚊𝚌𝚑𝚒𝚗𝚎, ⓑⓤⓛⓛⓔⓢ, 🄲🄰🅁🅁🄴🅂, ᴘᴇᴛɪᴛᴇꜱ ᴄᴀᴘɪᴛᴀʟᴇꜱ, ʇxǝʇ uᴉ ɹǝʌuǝ'l à, b̶a̶r̶r̶é̶…
- Copie en un clic (API Clipboard avec repli), raccourci <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Entrée</kbd>
- Gestion des lettres accentuées (conservées ou retirées : é → e)
- Lien de partage (`?t=votre+texte`) et mémorisation locale du dernier texte
- 100 % côté navigateur : aucun texte n'est envoyé à un serveur

## Développement

Un seul fichier statique : `index.html` (Tailwind CSS et Font Awesome via CDN). Ouvrez-le dans un navigateur, il n'y a rien à compiler. Le site est publié via GitHub Pages.
