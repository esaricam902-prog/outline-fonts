# outline-fonts

Convertisseur de texte en caractères Unicode stylés (Outline 𝔸𝔹ℂ, gras, italique, script, gothique, bulles…) à copier-coller.

👉 https://esaricam902-prog.github.io/outline-fonts/

- Conversion en temps réel vers 22 styles, copie en un clic
- Lettres accentuées converties (é → 𝕖), option désactivable
- Lien de partage (`?t=votre texte`) et mémorisation du dernier texte
- Raccourci <kbd>Ctrl</kbd> + <kbd>Entrée</kbd> pour copier
